# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** ([private advisory form](https://github.com/youssefsiam38/dsh-plugins/security/advisories/new)). Do not open a public issue, pull request, or discussion for a vulnerability.

Include the affected package and version, the dsh version, steps to reproduce, and the impact you expect. You will get an acknowledgement, and the fix is released before the advisory is published.

## Supported versions

Fixes go into the latest published version of each package.

## Scope

Issues in the plugins in this repository are in scope. Issues in DeepSeek Harness itself belong to the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) project.
